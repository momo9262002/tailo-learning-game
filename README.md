## 二、如何加入 Canva 簡報使用

Canva 簡報支援兩種方式整合本互動遊戲：

### 方法 A：在 Canva 簡報頁面上直接內嵌互動遊戲（推薦）
Canva 的「嵌入（Embed）」功能需要一個 `https://` 公開網址。您只需花 30 秒將 `index.html` 免費託管至以下任一平台：

1. **Netlify Drop（最快速，免寫程式）**
   - 前往 `https://app.netlify.com/drop`
   - 將 `台羅學習遊戲` 資料夾直接拖曳到網頁框中，即刻產生一組 `https://xxxx.netlify.app` 網址。
2. **GitHub Pages**
   - 將 `index.html` 上傳至 GitHub Repository 並開啟 GitHub Pages。

**在 Canva 嵌入步驟：**
1. 打開您的 **Canva 簡報（16:9）**。
2. 點選左側工具列的 **「應用程式（Apps）」** → 搜尋並選擇 **「嵌入（Embed）」**（或直接在簡報頁面按下鍵盤 `/` 輸入 `Embed`）。
3. 貼上剛剛產生的 `https://` 遊戲網址，即可將 **可實際點擊轉盤與抽題的互動遊戲** 直接嵌入簡報投影片中！

### 方法 B：在 Canva 設計自訂互動程式碼（Canva Code / 連結跳轉）
- 若您的 Canva 帳號已開啟 **Canva 程式碼（Canva Code）** 功能，也可複製 `index.html` 完整原始碼貼入。
- 或於 Canva 簡報按鈕設定超連結至遊戲網址，上課簡報點擊即跳出互動視窗。
